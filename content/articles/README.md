# Как добавлять статьи

Каждая статья — отдельный `.md` файл в этой папке. Имя файла без `.md` становится адресом статьи:

`my-new-article.md` → `/zapiski/my-new-article`

В начале файла нужен frontmatter:

```md
---
title: "Заголовок статьи"
category: "Категория"
description: "Короткое описание для карточки и SEO"
image: "/Картинка в public.png"
date: "2026-05-29"
published: true
---
```

Дальше пишется обычный Markdown: абзацы, `### подзаголовки`, списки через `-`, картинки через `![alt](/image.png)`, жирный текст через `**текст**`.

Если нужно скрыть статью с сайта, поставь:

```md
published: false
```
